# Checklist de entrega

Antes del día 22, prueba lo esencial en un entorno limpio.

## Web y PWA

- [ ] Abrir GitHub Pages y hacer una recarga dura.
- [ ] Instalar la PWA, abrirla instalada, probar sin conexión y volver a conectarla.
- [ ] Confirmar que aparece y funciona el aviso de actualización tras publicar una versión nueva.

## Juego

- [ ] Empezar un caso Normal, recargar y comprobar que el tablero se conserva.
- [ ] Resolver un Normal y confirmar progreso, logro y toast.
- [ ] Abrir y jugar Daily e Infinito; revisar Perfil.
- [ ] Si hace falta una prueba limpia, usar el reset de progreso.

## Móvil

- [ ] Revisar a 360 px los tableros 9×9 y 10×10, strip de personajes y toolbar.
- [ ] Abrir ResultModal y CheckpointModal en una pantalla corta.

## Android

- [ ] Instalar un APK limpio y comprobar el icono nuevo en launcher y cajón de apps.
- [ ] Abrir un caso, cerrarlo y reabrirlo para verificar la persistencia.
